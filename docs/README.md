# Плагин Simplify Logical Expression

### Автор: Демченко Алексей владимирович, группа M3102

## Задача расширения: упрощение выделенных логических выражений на C++.

- `Пользователь выделяет логическое выражение в редакторе кода Visual Studio Code, нажимает сочетание клавиш, чем запрашивает требование упростить выражение.`
- `Плагин обрабатывает логические операторы &&, ||, !, скобки, переменные, литералы true и false, а также операторы сравнения <, >, <=, >=, ==, !=. Сравнения обрабатываются как неделимые логические выражения.`
- `Обработка выражений происходит по следующим основным законам: нейтральный элемент, поглощение константой, двойное отрицание, идемпотентность, противоречие, исключенное третье, законы де Моргана, законы поглощения.`
- `При условии, что выделенное выражение является логическим, плагин заменяет его результатом. Если же выделенное выражение не является логическим выражением, информация об этом выводится в всплывающем предупреждении и код не изменяется.`
